Khác sơ đồ dự kiến của BT1

  • Thêm giao diện React phục vụ ngay trong Express (BT1 chỉ có API)
  • Thêm chế độ dữ liệu RAM để chạy và chấm bài khi không có Docker
  • Thêm request_id + bảng danh mục (migration 002, 003) và contract ánh xạ cột → trường API
  • CSDL chạy trong Docker cổng 5434 thay vì cài PostgreSQL trên máy
Luồng một yêu cầu: Trình duyệt → route → validator → service → repository → PostgreSQL, kết quả quay lại theo contract để giao diện không phụ thuộc tên cột CSDL. Nguyễn Nam Khánh · L2 · 2026
