# Nhật ký cập nhật

File này ghi lại các thay đổi đáng chú ý sau mỗi lần cập nhật dự án.

## 2026-09-28

### Đã làm
- Thêm quy trình ghi chú và hướng dẫn xem lịch sử cập nhật trên GitHub.
- Hoàn thiện tài liệu khai báo sử dụng AI.

### Kiểm thử
- `npm test` đạt.

### Commit
- `docs(workflow): add update log instructions`

## Mẫu cho lần cập nhật tiếp theo

```text
## YYYY-MM-DD

### Đã làm
- Sửa hoặc thêm chức năng nào.
- Cập nhật file nào nếu cần.

### Kiểm thử
- Lệnh đã chạy và kết quả.

### Commit
- feat(ticket): them chuc nang tao phieu bao hanh
```
