# Mẫu dữ liệu L2

Các file CSV trong thư mục này là mẫu nhỏ được trích từ bộ dữ liệu mô phỏng trong `dataset/` để kiểm thử cục bộ và được phép commit vào Git.

- `customers_sample.csv`: 100 hồ sơ khách hàng đầu tiên.
- `tickets_history_sample.csv`: 100 phiếu bảo hành đầu tiên.
- `ticket_status_log_sample.csv`: 200 dòng lịch sử trạng thái đầu tiên.
- `issue_categories.csv`: danh mục nhóm sự cố.
- `service_centers.csv`: danh sách trung tâm bảo hành.

Dữ liệu đầy đủ vẫn nằm trong `dataset/` ở máy cá nhân và bị loại khỏi Git bởi `.gitignore`.
